Settings

Control which features Oxidize shows and how it connects to Firefly III. Changes apply immediately and survive restarts.

Beta — Settings are not completely functional yet. Some options may still change or misbehave; please report anything odd.

Firefly III

Overrides FIREFLY_III_URL. This is the API base (e.g. https://firefly.example.com/api). Clear the field to fall back to the server environment value.

Overrides FIREFLY_III_ACCESS_TOKEN. Use a personal access token from Firefly III. Clear the field to fall back to the server environment value.

Accounts

Account types in the filter

Which Firefly account types are offered in the account type filter. Overrides ACCOUNT_TYPES.

Automatically fetch the account list when a page loads. Overrides AUTO_FETCH_ACCOUNTS.

Caching

How long chart data fetched from Firefly III is cached, in seconds. Overrides CACHE_TTL.

Time ranges

Comma-separated relative time ranges offered in the date filter (e.g. 7d, 30d, 3m, 6m, 1y, ytd). Overrides TIME_RANGES.

Which preset the date filter starts with. Overrides DEFAULT_TIME_RANGE.

Server

These values come from the process environment (the .env file or container env vars) and need a restart to change.

Bind address

Overrides HOST / PORT.

Data directory

Where the Oxidize database lives (DATA_DIR).

Log level

RUST_LOG, applied at startup.

Features

Show the Monthly Summary page. When disabled, the page and its navigation link are hidden everywhere.

Show the Sankey Flow page. When disabled, the page and its navigation link are hidden everywhere. Dashboard sankey widgets keep working.

Show the Reimbursements page. When disabled, the page and its navigation link are hidden everywhere.

Show the Budget Comparison page. When disabled, the page and its navigation link are hidden everywhere.

Show the Avg Cost page. When disabled, the page and its navigation link are hidden everywhere.

Show the Spending Labels page where you classify categories into your own lenses (e.g. wants vs needs) and report on them. When disabled, the page and its navigation link are hidden everywhere.
